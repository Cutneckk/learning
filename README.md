Задача:
(1) пишете собственный `HashMap` c **open addressing** (линейное/квадратичное пробирование на выбор) и считаете среднее число проб на вставку/поиск; 

(2) делаете `LRU`-декоратор `@lru(maxsize: int)` c поддержкой `*args/**kwargs` и `functools.wraps`, внутри — ваш `HashMap` + `deque`; 

(3) строите **приоритетную очередь** задач на `heapq` с резервной `deque` для равных приоритетов; 

(4) вставляете дедлайны отсортированно через **bisect**, а идентификаторы храните компактно в `array('I')`; 

(5) пишете **генераторный пайплайн** (`yield from`) для фильтрации/маппинга задач и отдельный **итератор** “скользящее окно” размера `k`; 

(6) добавляете два **менеджера контекста**: `Timing()` (замер и лог) и `suppress(*exc_types)`; 

(7) демонстрируете **LEGB**: счётчик через `nonlocal` в замыкании, глобальный флаг через `global`, плюс пример затенения `len`; 

(8) сравниваете `list` vs `deque` по `append/pop` и `dict` vs ваш `HashMap` по вставке/поиску (микробенчмарки в одном прогоне), фиксируете результаты в таблице; 

(9) показываете корректность через `pytest` (edge-кейсы: коллизии, переполнение `LRU`, равные приоритеты) и `mypy --strict` без ошибок; сдача — `pyproject.toml`, исходники `src/taskkit/`, `tests/`, `README.md` с инструкциями запуска и кратким анализом результатов.
