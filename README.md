обработки ошибок,
дандер методы
агрегация композиция
полиморфизм, инкапсуляцию (в питне _attr и __attr), наседование


Решение:
обработка ошибок (raise),
дандер методы __init__,
агрегация и композиция отмечена #комментарием,
полиморфизм реализован в классе Calculator(можно добавить еще один калькулятор со скидкой),
инкапсуляция protected и private отмечена #комментарием.
